📋 DXF Export Pipeline Refactoring (V4) – Complete Session Summary
🎯 Objective
Refactor the legacy DxfExporter into a modular, unit-testable V4 pipeline that decouples geometry calculations from netDxf until the final rendering step, while preserving WYSIWYG accuracy with the 3D rendering pipeline.

🏗️ Final Architecture: Rendering.V4

private static List<Vector2> BuildEndPanelWithToeKick(double depth, double height, double tkHeight, double tkDepth)
{
    return new List<Vector2>
    {
        new(depth, tkHeight), new(depth, height), new(0, height), new(0, 0),
        new(3, 0), new(3, 0.5), new(depth - tkDepth - 3, 0.5),
        new(depth - tkDepth - 3, 0), new(depth - tkDepth, 0), new(depth - tkDepth, tkHeight)
    };
}

Applied to "Right End" panels only
Mirrors across vertical centerline: X' = Bounds.Width - X, Y unchanged
Mirrors outline, thinning pockets, mortise pockets, and holes

Context Summary: CorlaneCabinetOrderFormV3 DXF Exporter
Overview
This is a C# module for exporting cabinet parts to DXF format for CNC machining. It uses the netDxf library to generate machine-ready files containing part outlines, joinery geometry (tenons/mortises), thinning pockets, screw pilot holes, shelf/drawer/hinge holes, grain direction arrows, and text labels.

Core Workflow
Orchestration (DxfExporter.ExportAll): Iterates through CabinetModel instances, builds parts via PartsListBuilder, and calculates joinery specs.
Routing: Parts are routed to ExportPart (standard panels) or ExportEndPanel (Left/Right ends with mortises).
Geometry Generation: PartOutlineBuilder computes tenon ranges, outlines, pockets, and hole positions based on LockDadoSettings.
DXF Construction: DxfExporter.Document helpers create layers, add polylines/circles/text, and save the file.
Key Classes & Responsibilities
DxfExporter (Partial Class)
ExportAll: Entry point. Calculates MortiseSpec, shelf holes, drawer slide holes, and hinge holes for base cabinets.
ExportPart: Handles standard parts (Deck, Back, Stretcher, Toekick). Adds outlines, tenon thinning pockets, and specific mortise/screw patterns for stretchers and backs.
ExportEndPanel: Handles Left/Right end panels. Applies CW90 rotation and X-mirroring (for Left ends) to outlines, mortise pockets, and holes.
ResolvePartKind: Maps part names to DxfPartKind enum to determine joinery requirements.
PartOutlineBuilder
ComputeTenonRanges: Divides an edge into alternating tenons and gaps.
Algorithm: Calculates usable length after blind pockets, determines gap/tenon count based on edge length, and distributes tenons evenly. Supports forceTwoTenons override.
BuildPanelWithTenons: Generates closed polyline vertices for parts with tenon protrusions. Traces perimeter counter-clockwise, adding protrusions on specified edges (EdgeDesignators).
ComputeTenonThinningPockets: Generates rectangular pockets on the flat face around tenons for weight reduction and CNC efficiency. Extends DadoDepth + 0.03937" outward from edges.
ComputeDepthDirectionMortisePockets / ComputeHeightDirectionMortisePockets: Calculates mortise pocket bounds for end panels based on tenon ranges and flush face.
ComputeDepthDirectionScrewHoles / ComputeHeightDirectionScrewHoles: Places screw pilot holes in gaps between tenons. Adds end fastening holes unless forceTwoTenons is true.
MortiseSpecBuilder
Computes MortiseSpec entries for end panels (Deck, Back, Top, Stretcher, Nailer, Toekick).
Handles component-specific overrides for BlindStart/Stop, TenonThickness, and forceTwoTenons.
Uses TenonFlushFace to determine mortise slot positioning relative to the end panel face.
Configuration & Models
LockDadoSettings (Record)
Shop-specific joinery parameters. Supports global defaults and per-edge overrides (BlindStartLeft, BlindStopRight, etc.).

Key Properties: BlindStart, BlindStop, GapWidth, GapCount, TenonThickness, TenonClearance, MortiseSlotHeight, MortiseOversize, DadoDepth, TenonPocketOversize, ScrewPilotHoleDiameter.
TenonFlushFace (Enum)
Controls which face of a tenon panel is flush (unrouted) and how mortise slots are positioned on the mating end panel.

Top: Mortise on outer/top surface (Deck, Full Top).
Bottom: Mortise on underside (Top Stretcher, Drawer Stretchers).
Front: Mortise recessed into interior (Nailer).
Back: Mortise on rear surface (Toekick).
EdgeDesignators (Flags Enum)
Specifies which edges have tenons: Left, Right, Top, Bottom, LeftRight, TopBottom, All.

DxfPartKind (Enum)
Classifies parts for export routing: Plain, TenonLeftAndRight, TenonTopAndBottom, TenonTopLeftRight, MortisePanel.

Coordinate System & Transformations
Standard Parts: Origin (0,0) at bottom-left. X = left-to-right, Y = bottom-to-top. Tenons extend outward beyond panel bounds.
End Panels:
Original Axes: X = cabinet depth, Y = cabinet height.
Export Transformation: Rotated 90° Clockwise so grain runs horizontally along X-axis.
Rotation Formula: (x, y) → (y, oldWidth - x).
Left End Mirroring: Mirrored across X-axis midpoint: x' = panelLength - x.
Hole/Pocket Rotation: Corresponding helpers (RotateHoleCW90, RotatePocketCW90) apply the same transformation to ensure geometry aligns with the rotated outline.
DXF Layers & Colors
Layers are pre-configured in CreateDocument with specific ACI colors for CAM differentiation:

outline z18p6 (White, 7): Part outlines.
pocket z10p0 (Red, 1): Tenon thinning pockets.
pocket [3185] z9p0 (Red, 1): Mortise pockets.
pocket [3185] z18p6 (Red, 1): Thru-mortise pockets.
drill z18p8 (Cyan, 4): Thru holes / Screw holes.
drill z13p0 (Cyan, 4): Shelf, Drawer Slide, and Hinge holes.
GRAIN_DIRECTION (Green, 3): Dashed line indicating grain direction.
LABELS (Yellow, 2): Part name, quantity, dimensions, material, edge band, and notes.
Constants & Defaults
MaterialDefaults.Thickness34: 0.75" (standard material thickness).
Shelf/Drawer/Hinge Hole Diameter: 0.1968" (~5mm).
Tenon Pocket Oversize Margin: 0.03937" (~1mm) added to DadoDepth for tool compensation.
